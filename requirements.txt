# Pinning policy (mirrors growspace_manager's ADR-0020): CI must resolve the same
# set on any given commit regardless of when it runs. Two mechanisms cover that,
# in order of precedence:
#

#   2. pytest-homeassistant-custom-component, which pins homeassistant plus the
#      whole pytest stack exactly (pytest, pytest-asyncio, pytest-cov,
#      pytest-xdist, coverage, freezegun, requests-mock, syrupy).
#
# Anything left bare would float under a fresh resolve. Add an explicit `==` pin
# for anything neither mechanism covers.
